# Your Marketing AI Workspace - Start Here

This folder is your personal AI marketing team. One place for all your work, with agents who know Systematics, know how you write, and get better every week.

It works in **Claude Code** and in **Codex**. Same folder, same agents, same skills.

---

## What's inside (2-minute tour)

| Folder / file | What it is | Do you edit it? |
|---------------|-----------|-----------------|
| `AGENTS.md` | The operating manual. Every rule the agents follow. | Rarely. Ask Sam to change it. |
| `CLAUDE.md` | Points Claude Code to `AGENTS.md`. | Never |
| `company.md` | Systematics context + **your team** (you fill in the bottom part). | Once, during setup |
| `context/` | Your voice, your audience, the guardrails, team learnings. | During setup, then the agents update it |
| `team/` | Your agents. One file each: personality, rules, what they've learned. | Agents update their own learnings |
| `skills/` | Step-by-step recipes for recurring work (LinkedIn post, event plan, case study...). | Add your own over time |
| `workflows/` | Saved chains of agents (e.g. Chloe writes, Iris reviews). | Add your own over time |
| `work/tasks/` | Every task you ask for, with its status. Created automatically. | No |
| `Projects/` | Bigger pieces of work with several tasks. One example inside. | Delete the example later |
| `deliverables/` | Final, approved outputs. | No |

## Setup (15 minutes)

### 1. Put the folder somewhere safe
Unzip it into a folder synced to OneDrive, for example `OneDrive/Marketing-Workspace-[your name]`. That way it's backed up and you can reach it from any computer.

### 2. Open it in your AI tool

**Claude Code (desktop app):** open the Claude app, go to **Code**, choose **Select folder**, and pick your workspace folder.

**Codex (desktop app or VS Code extension):** open Codex, choose **Open folder / project**, and pick your workspace folder.

### 3. Say hello
Type:

> **Let's set up my workspace.**

Sam will interview you in four short rounds: you and your team, goals and channels, your voice, your audience. Have ready:
- 2 to 3 things you wrote that you like (a post, an email)
- Your team's goals for this year
- Who approves customer-facing content

### 4. Give the team a first real task
For example:
> Chloe, write a LinkedIn post about our next webinar on [topic].

> Marcus, plan a campaign to get 20 demo meetings for [product] by [date].

> Iris, review this before I send it: [paste text]

## How to work with it every day

- **Just ask.** Talk to Sam, or call an agent by name.
- **Answer the questions.** Agents ask 1 to 3 questions when something is unclear. Good answers = good first drafts.
- **Give real feedback.** "Shorter", "too salesy", "the second hook". Agents learn from it.
- **Say "done" when it's done.** The agent then saves it to `deliverables/` and records what it learned.
- **Drop files in.** Brand book, past campaigns, a data export: put them in the folder and tell the agent where.

## Grow it

- **Third time you ask for the same kind of thing?** Say "Turn this into a skill."
- **Same agents in the same order every time?** Say "Save this as a workflow."
- **Need a specialist you don't have?** Say "Sam, hire someone for [events / SEO / design briefs]."
- **Plan your week:** "Sam, what should I focus on this week?"

## Rules that protect you

The agents follow `context/guardrails.md`: no invented facts or numbers, no customer names without written permission, vendor claims labeled, no prices, no defense details, opt-in email only. If an agent breaks one, tell it, and it will be added to the team learnings.

**Don't paste** contracts, customer personal data or classified information into the workspace.
